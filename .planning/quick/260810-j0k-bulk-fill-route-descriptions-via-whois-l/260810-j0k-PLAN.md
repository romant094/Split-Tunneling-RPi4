<objective>
Add a "Fill Descriptions" action to the Routes page that bulk-resolves org names for routes
with an empty description, using the existing `/api/diag/whois` endpoint, and stages the
results as pending changes until the user clicks Apply Changes.

Purpose: manually describing dozens of CIDRs is tedious; the whois/ASN lookup already used
for single-route add can do it in one pass.
Output: staged description edits in `routeStaging.js`, a batch-fill button with progress in
`Routes.jsx`, diff rendering of modifications, persistence on Apply, rebuilt `dist/`, docs.
</objective>
