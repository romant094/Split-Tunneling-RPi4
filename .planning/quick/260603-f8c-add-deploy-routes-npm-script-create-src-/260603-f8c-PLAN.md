## Objective

Add a lightweight script (`src/deploy-routes.sh`) that ships only the two custom-route config files (`isp-routes-custom.txt` and `vpn-routes-custom.txt`) to the RPi and re-applies routing without the full 28-stage `deploy.sh` pipeline. Wire it up via `npm run deploy-routes` and document it in the user-facing docs.

**Why this matters:**
- Editing custom-route CIDRs is a frequent, low-risk operation that does not require re-running AmneziaWG install, key validation, systemd reloads, etc.
- Current workflow: edit `src/configs/*-custom.txt` → `bash src/deploy.sh` (~28 stages, including kernel module checks, key validation, tunnel bring-up guards). This is heavy and slow.
- New workflow: edit → `npm run deploy-routes` (2 SCPs + 1 `routing.sh --no-update`). Seconds, not minutes.

**Output:**
- `src/deploy-routes.sh` (new, ~50 lines, mirrors `src/deploy.sh` patterns exactly)
- `package.json` (1-line addition to `scripts`)
- `README.md` updated (English user docs)
- `docs/README.ru.md` updated (Russian user docs — must stay in sync per CLAUDE.md convention)
- `docs/REFERENCE.md` updated (full operator reference)

1. Shebang `#!/usr/bin/env bash` + header comment block stating purpose ("Fast custom-routes-only deploy — skips AmneziaWG install, key validation, systemd setup.
