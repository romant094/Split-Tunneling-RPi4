    Edit `deploy.sh` to add Phase 2 deployment. The existing structure has TOTAL_STAGES=9 and 9 labeled stages. Make these changes:

    **1. Update TOTAL_STAGES:** Change `TOTAL_STAGES=9` to `TOTAL_STAGES=11` (add 2 new stages: routing.sh deploy + routing.sh activate).

    **2. Add --no-run argument parsing:** Near the top of the script (after the existing configuration block), add:
    ```bash
    RUN_ROUTING=true
    for arg in "$@"; do
      case "$arg" in
        --no-run) RUN_ROUTING=false ;;
        *) ;;
      esac
    done
    ```

    **3. Add routing.sh path constant:** In the constants/configuration block, add:
    ```bash
    ROUTING_SH_LOCAL="scripts/routing.sh"
    ROUTING_SH_REMOTE="/etc/routing.sh"
    ROUTING_SH_TMP="/tmp/routing.sh"
    ```

    **4. Add preflight check for routing.sh:** In Stage 1 (preflight), add a check that `scripts/routing.sh` exists alongside the existing checks for amnezia.key.claude.txt, .env, .env.secrets.

    **5. Add Stage 10 — Deploy routing.sh:** Insert after existing Stage 9 (the deploy complete message), BEFORE the final summary echo block:
    ```bash
    echo "[10/${TOTAL_STAGES}] Deploying routing.sh to ${SSH_HOST}:${ROUTING_SH_REMOTE}..."
    scp -o BatchMode=yes "${ROUTING_SH_LOCAL}" "${SSH_HOST}:${ROUTING_SH_TMP}"
    ssh -o BatchMode=yes "${SSH_HOST}" "sudo mv ${ROUTING_SH_TMP} ${ROUTING_SH_REMOTE} && sudo chmod +x ${ROUTING_SH_REMOTE}"
    echo "       routing.sh deployed to ${ROUTING_SH_REMOTE} (chmod +x)"
    ```

    **6. Add Stage 11 — Activate routing.sh (unless --no-run):** Insert after Stage 10:
    ```bash
    if [ "${RUN_ROUTING}" = "true" ]; then
      echo "[11/${TOTAL_STAGES}] Activating routing.sh on ${SSH_HOST}..."
      ssh -o BatchMode=yes "${SSH_HOST}" "sudo ${ROUTING_SH_REMOTE}"
      echo "       routing.sh activation complete — split-tunnel active"
    else
      echo "[11/${TOTAL_STAGES}] Skipping routing.sh activation (--no-run). Run manually:"
      echo "       ssh ${SSH_HOST} \"sudo ${ROUTING_SH_REMOTE}\""
    fi
    ```

    **7. Update final summary block:** In the existing summary echo block (the === Phase 1 deploy successful === section), update it to say "Phase 1 + 2 deploy successful" and add Phase 2 verification commands:
    ```
    Deployed:
      ROUT-01..04 + NAT-01..03: ${ROUTING_SH_REMOTE} (chmod +x)
    
    Phase 2 verification (run on RPi):
      ip route show default         # expect dev awg0
      ip route get YOUR_VPN_SERVER_IP    # expect via 192.168.1.1 (ISP)
      ip route get 77.88.8.8       # expect via 192.168.1.1 (RU → ISP)
      ip route get 8.8.8.8         # expect dev awg0 (foreign → VPN)
      sudo iptables -t nat -L POSTROUTING -n -v   # expect MASQUERADE on awg0 + eth0
    
    If --no-run was used, activate routing manually:
      ssh pi4 "sudo /etc/routing.sh"
    ```

    Do NOT change any existing Stage 1–9 logic. Only add Stage 10, Stage 11, the --no-run flag, the routing.sh constants, and the summary update.
