DAEMON LOG LINE FORMAT (confirmed from src/scripts/watch-routes.py `_write_daemon_line`, line 466):
`{ts} [{tag}] {status} {src} → {dst_part} {port_part} | {org}`
- `ts` example: `2026-05-21T11:36:21+0300` (ISO 8601 with offset)
- `tag` = `VPN` or `ISP`
- `status` = `✓` or `✗` (may be empty when conntrack unavailable)
- `dst_part` = `IP (hostname)` or bare `IP`; `port_part` = `TCP:443`
