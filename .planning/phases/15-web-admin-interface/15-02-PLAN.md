- H2 "Route Exceptions"
- "Apply Routes" button (id="btn-apply") at top — calls POST /api/config/apply, shows `<div id="apply-result">` with "rc=N" feedback
- Two sections: "VPN Routes" and "ISP Routes", each:

- `activateTab(name)`: hides all .tab-pane, removes active class from all tab buttons; shows target pane, adds active class to button; if name==="routes", calls loadRoutes('vpn') and loadRoutes('isp'); if name==="logs", starts SSE (see Task 2); if name==="status", calls loadStatus()
