    - GET /api/logs → text/event-stream; opens /etc/splitgate/logs/watch-YYYY-MM-DD.log (today's date), tails new lines via seek-to-end; each new line emitted as SSE `data: <line>\n\n`; if file absent, emits `data: [log file not found]\n\n` then holds connection open retrying every 2s

  <action>
Create src/scripts/splitgate-admin.py as a single standalone Python 3 script.

Structure:
1. Shebang + module docstring listing all endpoints and decisions (D-15-01 through D-15-06).
2. Imports: flask (Flask, request, Response, abort), subprocess, os, re, datetime, functools, secrets, time.
3. Constants block at top:
   - SECRET_FILE = "/etc/splitgate/admin.secret"
   - VPN_CUSTOM = "/etc/splitgate/vpn-routes-custom.txt"
   - ISP_CUSTOM = "/etc/splitgate/isp-routes-custom.txt"
   - EXCLUDE_FILE = "/etc/splitgate/ru-list-exclude.txt"
   - LOG_DIR = "/etc/splitgate/logs"
   - ADMIN_PORT = int(os.environ.get("ADMIN_PORT", "8080"))
   - KEENETIC_GW = os.environ.get("KEENETIC_GW", "192.168.1.1")
4. Auth helper: `require_auth` decorator that reads SECRET_FILE (strip whitespace), compares using `secrets.compare_digest` against the Authorization header's decoded Basic credentials. If SECRET_FILE missing, aborts 500 with a setup hint. Unauthed → 401 with WWW-Authenticate header.
5. CIDR validation helper: `valid_cidr(s)` — regex `^\d{1,3}(\.\d{1,3}){3}/\d{1,2}$` plus each octet 0-255, prefix 0-32. Returns bool.
6. Route file helpers:
   - `read_routes(path)` → list of non-comment, non-empty lines
   - `append_route(path, cidr)` → opens file in append mode; writes `\n{cidr}` (creates file if absent)
   - `remove_route(path, cidr)` → rewrites file excluding lines that equal cidr (strip)
7. Status endpoint (`/api/status`):
   - `tunnel_up`: run `subprocess.run(["sudo", "awg", "show"], capture_output=True, timeout=3)`; up if rc==0 and stdout non-empty
   - `daemon_up`: run `subprocess.run(["systemctl", "is-active", "splitgate-watch"], capture_output=True, timeout=3)`; up if stdout.strip()=="active"
   - `ru_list_updated`: read last line of /etc/splitgate/logs/install.log containing "Downloaded"; extract date
   - `vpn_route_count`: len(read_routes(VPN_CUSTOM))
   - `isp_route_count`: len(read_routes(ISP_CUSTOM))
   - `ru_route_count`: run `subprocess.run(["ip", "route", "show", "via", KEENETIC_GW], ...)` or read /etc/splitgate/white-list.txt line count if faster
8. Route endpoints: three Flask routes each for /api/routes/vpn and /api/routes/isp (GET / POST / DELETE), all decorated with @require_auth. POST validates CIDR first. DELETE returns 404 if CIDR not in file.
9. Config endpoints: GET+PUT /api/config/exclude; POST /api/config/apply; POST /api/config/update. All @require_auth.
10. SSE endpoint (`/api/logs`): generator function that opens today's log file (LOG_DIR/watch-YYYY-MM-DD.log), seeks to end, then loops: reads new data; if data, yields `data: {line}\n\n`; else time.sleep(0.5). Wrapped in `Response(generate(), mimetype="text/event-stream")`. All @require_auth.
11. Root route (`/`): returns embedded HTML string (Task 2 in Plan 02 fills this out fully; for now a minimal skeleton with 4 tab headings is sufficient).
12. `if __name__ == "__main__"`: `app.run(host="0.0.0.0", port=ADMIN_PORT, threaded=True)`.

CIDR file writes require the process to run as root (which the systemd service does). Do not use sudo for file writes — direct open() is fine when running as root.

Subprocess calls that need privilege (awg show, routing.sh, update-vpn-routes) must call sudo explicitly in the argv list because the Flask process itself will run as root under systemd; however, keep sudo in the list for local dev safety.

Do not use flask-login, flask-wtf, or any Flask extension beyond Flask itself (the flask package from python3-flask on Debian includes only the core).

The embedded HTML skeleton (placeholder for Plan 02) should be a minimal but valid HTML5 page with: title "Splitgate Admin", 4 tab buttons (Status / Routes / Config / Logs), empty content divs, and a `<script>` that loads the correct tab on click.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LAN → admin HTTP | Unauthenticated LAN device reaches port 8080 |
| admin service → RPi system | Flask runs as root; it executes system commands and writes config files |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Spoofing | Basic Auth | mitigate | `secrets.compare_digest` (constant-time); password stored chmod 600 root:root in /etc/splitgate/admin.secret |
| T-15-02 | Tampering | Route file writes | mitigate | `valid_cidr()` validates every CIDR before append_route(); no shell expansion in file ops (direct open()) |
| T-15-03 | Tampering | /api/config/exclude PUT | mitigate | Content length cap 64 KB; strip null bytes before write; no eval/exec |
| T-15-04 | Elevation of privilege | subprocess calls | mitigate | Fixed argv lists (no shell=True, no user-supplied shell strings); only known binaries called |
| T-15-05 | Information disclosure | Error responses | mitigate | Generic 500 on exceptions; exception detail logged server-side only (not in response body) |
| T-15-06 | DoS | SSE /api/logs | accept | LAN-only service; single-user; no rate limiting needed for home lab context |
| T-15-SC | Tampering | python3-flask apt install | mitigate | Install from official Debian apt repos only (no pip, no PyPI); apt verifies package signatures |
</threat_model>
