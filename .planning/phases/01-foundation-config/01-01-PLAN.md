    Stage 1 — Idempotency short-circuit: If `command -v awg >/dev/null 2>&1` AND `command -v awg-quick >/dev/null 2>&1`, log `[install-awg] AmneziaWG already installed — skipping package install` and jump to Stage 4 (sysctl) and Stage 5 (config dir).     Stage 2 — Primary install path (per D-01): Run the bivlked installer (RomikB fork). Use `curl -fsSL` to download https://raw.githubusercontent.com/RomikB/amneziawg-install/main/amneziawg-install.sh to a temp file, then `bash <tempfile>` with non-interactive defaults if possible. The installer auto-detects the RPi `+rpt` kernel suffix and selects `linux-headers-rpi-v8` per RESEARCH.md Pitfall 2. Capture installer exit code; if non-zero, log a clear error and fall through to Stage 3.

    Stage 3 — Fallback path (per D-02): Document via inline comments how to manually install from the GitHub releases page (https://github.com/amnezia-vpn/amneziawg-linux-kernel-module/releases). The fallback executes: `apt-get update`, `apt-get install -y linux-headers-rpi-v8`, then `apt-get install -y` against a `.deb` URL passed via an `AWG_DEB_URL` environment variable. If `AWG_DEB_URL` is unset and primary failed, exit 2 with message `[install-awg] ERROR: Primary install failed and AWG_DEB_URL not set — see scripts/install-awg.sh fallback comments`.

    Stage 4 — Persistent IP forwarding (INST-02): `sysctl -w net.ipv4.ip_forward=1` for immediate effect; then write the single line `net.ipv4.ip_forward=1` to `/etc/sysctl.d/99-vpn-gateway.conf` (overwrite — idempotent); then `sysctl --system` to reload. Verify with `sysctl -n net.ipv4.ip_forward` and exit non-zero if not `1`.

    Stage 5 — Pre-create config dir (per RESEARCH.md Pitfall 4): `mkdir -p /etc/amnezia/amneziawg` (owned root by virtue of running under sudo). Do NOT chmod — default 0755 is correct.

    Stage 6 — Post-install verification: Run `modprobe amneziawg` (kernel module load). Run `lsmod | grep -q '^amneziawg '`. Run `which awg` and `which awg-quick` and echo the resolved paths. On any failure, exit non-zero with a message naming the failing check.

    The script MUST be safe to run under `sudo bash -s` over SSH (no TTY assumptions, no `read` prompts, no color codes that depend on a terminal). Do NOT bring up the tunnel (`awg-quick up awg0`) — per RESEARCH.md Pitfall 5, that belongs to manual verification, not this script. Use D-01, D-02, D-03 decisions to label comments at the top of the file.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| macOS workstation → RPi (`pi4`) | Untrusted network in transit; SSH provides confidentiality + integrity; SSH key auth (D-06) provides identity |
| RPi userspace → RPi kernel | Installer compiles/loads `amneziawg.ko`; supply-chain trust placed on bivlked installer and Amnezia PPA |
| `curl | bash` execution of bivlked installer | Network-fetched code executed as root on RPi |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | bivlked installer fetched via `curl` | mitigate | Use HTTPS (`https://raw.githubusercontent.com/...`) with `-fsSL`; pin to RomikB fork main; document the URL in script comments so changes are reviewable in git; fallback path uses pinned `apt-get install` against signed PPA |
| T-01-02 | Elevation of Privilege | Script runs as root via `sudo bash -s` | mitigate | Script uses `set -euo pipefail` to fail fast on any error; no `read` prompts (no TTY hijack surface); scope limited to package install + sysctl drop-in + mkdir |
| T-01-03 | Denial of Service | DKMS compilation may take 10-30 min on kernel mismatch | accept | Acknowledged in RESEARCH.md (Pitfall 2); installer handles it; user expectation set via progress logging |
| T-01-04 | Information Disclosure | sysctl.d file contents | accept | `/etc/sysctl.d/99-vpn-gateway.conf` contains only `net.ipv4.ip_forward=1` — no secrets |
| T-01-05 | Tampering | `/etc/amnezia/amneziawg/` directory permissions | mitigate | Created via `mkdir -p` under sudo → owned `root:root` mode 0755 by default; Plan 02 enforces 0600 on awg0.conf inside it |
| T-01-SC | Tampering | apt/curl-bash supply chain | mitigate | Primary path uses bivlked installer (community-vetted, RESEARCH.md confirmed); fallback uses official AmneziaWG PPA with GPG-keyed signing; no npm/pip installs — slopcheck not applicable |
</threat_model>
