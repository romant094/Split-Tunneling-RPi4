<!-- Interface contract that Plan 02 and Plan 03 will consume via subprocess. Keep this stable. -->

CLI contract for scripts/asn-lookup.py:

Invocation:
  python3 scripts/asn-lookup.py            # reads IPs from stdin (one per line), writes JSON to stdout
  python3 scripts/asn-lookup.py --help     # prints usage
  python3 scripts/asn-lookup.py 8.8.8.8 1.1.1.1   # OPTIONAL direct-CLI mode (positional IPs)

stdin format:
  One IPv4 dotted-quad per line. Empty lines ignored. Whitespace stripped.

stdout format:
  Exactly one line: a JSON object of the shape:
    {"8.8.8.8": {"asn": "15169", "org": "GOOGLE, US"}, "1.1.1.1": {"asn": "13335", "org": "CLOUDFLARENET, US"}}
  IPs absent from the dict mean "no result" (either parse failed, Cymru unreachable, or IP not announced in BGP).
  An empty stdin produces "{}\n".

exit codes:
  0 — always (network errors are NOT fatal; missing IPs are simply absent from the dict)
  1 — unrecoverable internal error (e.g. cannot import json — should not happen on RPi)

Cache file:
  Path: /tmp/vpn-asn-cache.json
  Format: same shape as stdout dict: {"<ip>": {"asn": "<asn-digits>", "org": "<as-name>"}}
  Lifecycle: read at startup; merged with new results from Cymru; atomic-rewritten at end.
  Permissions: created world-writable (mode 0o666) on first creation so root + non-root invocations can share it.

    Create `scripts/asn-lookup.py` as a standalone executable Python script implementing the locked CLI contract above. Required structural elements:

    - Shebang `#!/usr/bin/env python3` and a top-level docstring describing usage, mirroring the style of `scripts/watch-routes.py`.
    - Stdlib-only imports: `argparse`, `json`, `os`, `socket`, `sys`, `tempfile`. No pip packages (D-09).
    - Module-level constants: `CACHE_FILE = "/tmp/vpn-asn-cache.json"`, `CYMRU_HOST = "whois.cymru.com"`, `CYMRU_PORT = 43`, `DEFAULT_TIMEOUT = 10.0`.
    - Function `_cymru_bulk_lookup(ips: list[str], timeout: float = DEFAULT_TIMEOUT) -> dict[str, dict]`:
      * Returns `{}` on empty input without opening a socket.
      * Opens one TCP socket; calls `s.settimeout(timeout)` BEFORE `s.connect()` (Pitfall 3).
      * Sends `"begin\nverbose\n" + "\n".join(ips) + "\nend\n"` encoded as bytes.
      * Reads via `s.makefile("rb")` and iterates lines.
      * Skips lines starting with `"Bulk mode"` or that contain no `"|"` (Pitfall 1).
      * Splits each remaining line by `"|"` and strips each part (Pitfall 2).
      * For lines with ≥7 fields: takes index 0 as `asn`, index 1 as `ip`, index 6 as `org`.
      * Wraps the whole socket block in `try/except (socket.timeout, OSError):` returning partial results (Pitfall 3).
    - Function `load_cache() -> dict`: opens CACHE_FILE for read; on `FileNotFoundError` or `json.JSONDecodeError` returns `{}`.
    - Function `save_cache(cache: dict) -> None`: uses `tempfile.mkstemp(dir=os.path.dirname(CACHE_FILE) or ".")` then `os.fdopen` + `json.dump` + `os.replace(tmp, CACHE_FILE)`. On any exception unlink the temp file. After successful replace, call `os.chmod(CACHE_FILE, 0o666)` (Pitfall 4 — both root and non-root callers must be able to update).
    - Function `lookup_ips(ips: list[str]) -> dict[str, dict]`: load cache → split ips into cached and uncached → call `_cymru_bulk_lookup(uncached)` → merge results into cache → save cache → return the subset of the cache restricted to the requested IPs.
    - `main()`:
      * `argparse.ArgumentParser` with description referencing stdin/stdout contract and CACHE_FILE path.
      * Optional positional `ips` (`nargs="*"`) for direct-CLI mode; if any positional IPs are given, use those; otherwise read IPs from `sys.stdin` (one per line, stripped, empty lines dropped).
      * Print `json.dumps(result)` followed by `\n` on stdout. No pretty-printing; one line only (so downstream bash can capture in a variable).
      * Always exit 0 unless an internal `ImportError`-class failure occurs.
    - `if __name__ == "__main__": main()` guard.
    - Make the file executable by leaving execution mode handling to git/deploy: write the file with the shebang; the deploy stage (Plan 03) and tests below verify chmod separately.

    Implement tests in `tests/test_asn_lookup.py` covering Test 1 through Test 13 above, using `unittest.mock.patch` for Cymru socket calls (do NOT hit the live Cymru service from the test suite — Cymru anti-abuse policy explicitly forbids this in CI). For Tests 1 and 2 use a recorded fixture response (Bulk mode header line + one or two synthetic pipe-separated rows) so the parse path is exercised without network. For the cache permission test (Test 9), point `CACHE_FILE` at a `tempfile.mkdtemp()` path via monkeypatch.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| RPi → Internet (TCP 43) | Outbound to whois.cymru.com:43 — untrusted server response parsed into JSON |
| asn-lookup.py ← stdin | Caller (vpn-status.sh, watch-routes.py) feeds IPs extracted from iptables LOG entries; IP strings are not directly user-supplied but pass through kernel log buffers |
| /tmp/vpn-asn-cache.json | Cache file lives on RPi tmpfs; shared between root (vpn-status.sh sudo) and non-root (watch-routes.py) — concurrent writes possible |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering | Cymru response stream (untrusted upstream) | mitigate | Strict parse: skip non-pipe lines, require ≥7 fields, strip whitespace; never `eval`; result keys validated as keys (no shell expansion) |
| T-07-02 | Denial of Service | whois.cymru.com unreachable / slow | mitigate | `socket.settimeout(10.0)` before connect; broad `try/except (socket.timeout, OSError)` returns empty dict — callers degrade to `-` per D-06/D-08 |
| T-07-03 | Tampering | Cache file corruption mid-write | mitigate | `tempfile.mkstemp` + `os.replace` atomic rename; on exception unlink tmp file; `load_cache` returns `{}` on `json.JSONDecodeError` |
| T-07-04 | Information Disclosure | Cache file readable by non-root | accept | Cache holds only public BGP ASN/org data (no PII, no secrets); mode 0o666 by design (Pitfall 4) |
| T-07-05 | Denial of Service | Team Cymru abuse-trigger (single-IP query loop) | mitigate | Always batch uncached IPs into one TCP session via `_cymru_bulk_lookup(list)`; never per-IP loop |
| T-07-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this phase — stdlib only (D-09); Package Legitimacy Audit in RESEARCH.md confirms "Not applicable" |
</threat_model>
